## Rendering notes

Serene tiles use a native 16px grid, displayed at 2× inside the map's 1000×1000
coordinate system. Each Townspeople character occupies a 54×104 block:
three 18×26 frames across, four directions down / left / right / up vertically.
The renderer uses a 0-1-2-1 walking cycle and frame 1 when idle or reduced-motion.
The existing animation clock controls travel, pause, triple speed, and following.
