# Elsewhere design contract

## Stack
- Framework: native browser ES modules; Node.js standard-library development server.
- Styling: plain CSS custom properties. No runtime dependencies.
- Graphics: top-down pixel neighborhood using the supplied Serene Village and Townspeople PNG atlases through native SVG viewports. The forest, buildings, paths, pond garden and seven directional actors share a 16px/2× overworld scale. Original full-body anime expression atlases, painted backgrounds and character-event CGs remain in story/profile views. Third-party pixel art is credited in assets/world/README.md and the game footer.
- Animation: one requestAnimationFrame clock for street-following movement and camera tracking; reduced-motion mode shows travel as discrete stops and removes decorative motion.

## Tokens
- Brand / text: crimson #8B3155 / ink #2D2D43.
- Canvas / surface: soft lilac #F6F3F7 / #FFFFFF.
- Secondary text: #696276. Accent: peach #F6D7AD, lavender #E0D5F3, sakura #F6D2DF.
- Story scenes: midnight #181626, raised surface #242035, text #FFF6ED, secondary #CBBFCF, gold #EDCC98, crimson #B73558. Scene and character illustration palettes use their own custom properties.
- Radius: 12px panels, 8px controls, pill badges.
- Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40px.
- Full token map lives in style.css. Illustrated scene colors are art palette tokens.
