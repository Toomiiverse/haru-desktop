# Haru Desktop design contract

## Stack
React 19, Vite, Electron; existing CSS in src/styles.css and src/live2d.css. Lucide icons. Three.js for VRM avatars; Pixi for Live2D.

## Tokens
Reuse the existing --bg, --surface, --text, --text-2 and accent tokens in src/styles.css. The avatar canvas stays transparent. No new styling dependency or duplicate stylesheet is needed.

## Components
- src/components.tsx: Persistent desktop navigation (Topbar), message avatars, two-row Composer, Your plans panel, and five native settings disclosures. Navigation uses aria-current, controls retain keyboard focus and explicit accessible names.
- src/App.tsx: Workspace header, page descriptions, Plans visibility control, chat loading skeleton and welcome state. Existing chat, Study, memory and settings behavior stays wired to the same handlers.
- src/StudyPage.tsx: Native desktop study workspace; topic, four learning activities, existing attachment composer and filtered shared conversation. Styles in src/study.css reuse the current theme tokens.
- src/components/VRMCanvas.tsx: 3D avatar, existing loading/error presentation, existing companion hitbox and dialogue.
- src/components.tsx: CharacterModelRow, shared avatar chooser for VRM and Live2D.
